# 🌱 TreePlantingGame

A simple casual mini‑game with multi‑platform real‑time synchronization.

---

## 🚀 How to Run

Follow the steps below to run the game locally:

### **Step 1: Install Node.js**

Make sure you have **Node.js** installed (LTS version recommended).

### **Step 2: Clone the repository**

```bash
git clone https://github.com/TommyLamm/TreePlantingGame
```

### **Step 3: Install dependencies**

```bash
npm install
```

### **Step 4: Start the server**

```bash
node server.js
```

### **Step 5: Open the game**

Open your browser and visit:

```
http://127.0.0.1:7777
```
